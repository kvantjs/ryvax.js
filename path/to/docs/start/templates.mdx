# Ryvax.js templates

Explore a curated collection of open-source application templates designed to demonstrate what can be built with Ryvax.js. Each template combines a refined interface with a practical full-stack foundation, giving teams a stronger starting point for products that need speed, clarity, and room to evolve.

> **Built with Ryvax.js** — React-first development, typed boundaries, server capabilities, streaming workflows, and an architecture designed for real products.

## Documentation platform

The Documentation Platform template turns technical knowledge into a clear, navigable product experience. It includes an expressive content structure, API exploration, interactive playgrounds, OpenAPI reference data, search-oriented navigation, and a visual system designed for long-form technical content.

### Designed for

| Product surface | Value |
| --- | --- |
| Framework documentation | Explain architecture, APIs, conventions, and production practices in one coherent experience. |
| Developer platforms | Combine guides, references, examples, and interactive exploration without fragmenting the journey. |
| API products | Present contracts, operations, request examples, and conceptual guidance side by side. |

[Explore the Documentation Platform template →](https://github.com/kvantjs/ryvax-docs-template)

## AI chat experience

The AI Chat template provides a sophisticated foundation for conversational products. It combines a focused interface with server-side model communication, streaming responses, conversation history, model fallback, optional search grounding, and a structure that can grow into a broader agent experience.

### Designed for

| Product surface | Value |
| --- | --- |
| AI assistants | Give users a calm, focused environment for asking questions and exploring ideas. |
| Internal copilots | Extend the interface with domain knowledge, tools, permissions, and organization context. |
| Agent experiences | Evolve from streaming conversations toward controlled workflows with durable state and evaluation. |

[Explore the AI Chat template →](https://github.com/kvantjs/ryvax-ai-chat-template)

## A shared engineering foundation

Both templates demonstrate the same principles that guide Ryvax.js applications:

<Columns cols={3}>
  <Card title="Typed boundaries" icon="shield-check">
    Keep application behavior explicit across the client, server, data, and integration layers.
  </Card>
  <Card title="Responsive experiences" icon="bolt">
    Use streaming and progressive feedback where waiting for a complete response would weaken the experience.
  </Card>
  <Card title="Room to grow" icon="arrow-up-right-dots">
    Begin with a focused product surface and evolve toward richer workflows without replacing the foundation.
  </Card>
</Columns>

## Open source by design

The templates are public so that developers can study the structure, adapt the visual language, propose improvements, and build new products from a transparent foundation. The repositories are intentionally useful as both working applications and architectural references.
